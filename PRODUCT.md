# Product

## Register

product

## Users

AI tooling builders and evaluators who compare coding assistants, system prompts, and benchmark outcomes during hands-on product and engineering work. They use the app while reviewing model behavior, recording results, and deciding which model or prompt setup is worth reusing.

## Product Purpose

This product documents AI coding tools, their prompts, and model-test results in one inspectable workspace. Success means a user can move from prompt context to a structured test suite, record comparable evidence for each model, and review the ranking without rebuilding the setup every time.

## Brand Personality

Precise, technical, focused.

## Anti-references

Avoid marketing dashboards, decorative benchmark pages, oversized hero treatments, and vague scorecards that hide the underlying evidence. The interface should not look like a landing page or a toy demo.

## Design Principles

- Preserve evidence over decoration: screenshots, notes, and rubric values must be easier to inspect than decorative chrome.
- Keep repeated workflows dense and predictable: adding models, challenges, and results should feel like operating a tool.
- Make comparison obvious: model rankings, missing data, and weak spots should be visible without hunting.
- Keep production boundaries explicit: local fallback, Convex persistence, and upload availability should be clearly signaled.
- Favor standard controls: forms, tables, tabs, dialogs, sliders, and file inputs should behave like familiar product UI.

## Accessibility & Inclusion

Target WCAG AA contrast for text and controls. Preserve keyboard access for dialogs, forms, sliders, and file inputs. Respect reduced-motion preferences and avoid relying on color alone for rubric meaning.
